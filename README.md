# The Home Workshop
This is a social website to help people who want to do home improvement and do-it-yourself projects and don't know how or where to start, and who need more guidance than a video that shows a time-lapse of the project. They need a human to walk them through it step-by-step, or to be able to vent when things go wrong, or they want to find a weekend workshop in their neighborhood. This site will help them with all of the above and more.



## Technology used 
This base repository will only hold the HTML and CSS. This project is a website, not an app, and it's built without using any frameworks, so everything will be coded by me!

## Challenges
I will be using flexbox for the layout. Not my strong suit, but building this should make me better.

## Accessibility
My goal is for this website to be born accessible. I will be following the WCAG 2.2 Level AAA standards for this. I will make sure that at the end, I write up a report of what accessibility testing sites I used.
